# 局域网联调接入测试

记录让同一局域网的同事访问控制面 API 的接入方式、测试步骤与命令。

## 1. 方式介绍

- 目的：让同事访问运行在 Ubuntu 虚拟机（UTM）内的控制面 API。
- 背景：控制面只监听 VM 内的 `127.0.0.1:18090`（代码强制 loopback），同事无法直接连 VM。
- 做法：用 SSH 端口转发（`-L`）把控制面端口绑定到 Mac 的局域网 IP，同事直连该 IP。

链路分两段：

```
同事 ──①──► Mac 局域网IP:18090 ──②──► VM 127.0.0.1:18090（控制面）
              （明文 HTTP）             （SSH 加密隧道）
```

特点：

- 不需要知道同事的 IP（她主动连你的 Mac）；
- 明文 HTTP，仅限内网可信同事，不暴露公网；
- DeepSeek Key 不经过此端口，无泄露风险。

## 2. 涉及地址

| 地址 | 含义 | 怎么查 |
|---|---|---|
| `127.0.0.1`（VM 内） | 控制面绑定地址 | 固定 |
| Mac 局域网 IP | 同事访问目标 | Mac 上 `ipconfig getifaddr en0` |
| VM_HOST | Ubuntu VM 的 IP | VM 内 `hostname -I`，或 Mac 上 `cat .env` |
| VM_USER | Ubuntu 登录用户名（非 IP） | `cat .env` |

本次实测值：Mac `192.168.76.97`，VM `agentdev@192.168.64.3`。这些是环境相关值，换网络后会变。

## 3. 前置条件

1. Ubuntu 虚拟机已启动。
2. 控制面已启动：`./run.sh start`。
3. 已给同事建账号：`./run.sh configure-user`（用单独用户名）。

## 4. 暴露到局域网（你这边执行）

```bash
ssh -N -L 192.168.76.97:18090:127.0.0.1:18090 agentdev@192.168.64.3
```

- 含义：监听 Mac 的 `192.168.76.97:18090`，经 SSH 转发到 VM 的 `127.0.0.1:18090`。
- 保持前台运行，别关终端；或加 `-f` 放后台：`ssh -fN -L ...`。
- 首次绑定非回环地址，macOS 可能弹「允许 ssh 接受传入连接」，点允许。
- 若想同时保留本机 `127.0.0.1:18090` 访问，监听地址改成 `0.0.0.0`：
  ```bash
  ssh -N -L 0.0.0.0:18090:127.0.0.1:18090 agentdev@192.168.64.3
  ```

## 5. 同事验证三步

假设目标地址为 `http://192.168.76.97:18090`。

**① 网络连通（无需登录）**

```bash
curl http://192.168.76.97:18090/healthz
```

期待：`{"status":"ok"}`

**② 登录拿 Cookie**

```bash
curl -c /tmp/c.txt -X POST http://192.168.76.97:18090/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin01","password":"1234abcd"}'
```

期待：返回 `user` 与 `expiresAt`。

**③ 鉴权与取数**

```bash
curl -b /tmp/c.txt http://192.168.76.97:18090/api/workspaces
```

期待：返回 `{"workspaces":[...]}`。

## 6. 通过标准

- ① 返回 200 → 网络链路通；
- ② 返回 200 + `user` → 账号密码可用；
- ③ 返回 200 + `workspaces` → Cookie 鉴权通，可开始开发。

## 7. 停止暴露

在你 Mac 上：

- 前台运行时按 `Ctrl-C` 关闭 `ssh -N`；
- 后台运行时按端口杀进程：`lsof -ti :18090 | xargs kill`（确认杀的是 ssh 转发进程）。

## 8. 安全说明

- 方式 A/B 的「同事 → Mac」段为明文 HTTP，同网段可被抓包；
- 仅用于内网可信同事的联调，不长期明文裸奔、不暴露公网；
- 更安全的方式是 SSH 反向隧道（全程加密），代价是需要同事机器开 SSH。
